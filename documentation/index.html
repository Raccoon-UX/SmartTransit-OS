CHAPTER 01 — FOUNDATION ST-01 → ST-95 (v2.4.0 Production)

SmartTransit OS — Technical Documentation

SmartTransit OS is an AI-powered smart city public transportation and urban mobility platform engineered for municipal transit corporations (such as MSRTC, BEST, and TMT). It integrates multi-channel emergency SOS dispatch, real-time fleet telemetry, custom vector city mapping, predictive occupancy inference, and role-based operational controls into a unified web application.

CHAPTER 13 — HOW TO USE

Complete Web Application Operations Guide

Step-by-step instructions for commuters, bus pilots, dispatch administrators, SOC security engineers, and AI operators.

👤

1. Passenger Commuter Hub

Public Transit Navigation & Route Search
  • 1. Live Bus Radar: Open /passenger/live-map to inspect real-time bus locations on the realistic vector city map with layer toggles (City, Traffic, Corridors, Satellite).
  • 2. Smart Journey Planner: Navigate to /passenger/journey-planner, enter origin and destination to compute fastest multimodal transit paths with transfer points and carbon emission savings.
  • 3. Saved Corridors & Stops: Bookmark frequent routes to access immediate arrival countdowns on your dashboard.
  • 4. Marathi Localization: Click the language toggle button EN / मराठी in the header to switch the interface instantly.
👨‍✈️

2. Driver Cockpit & Navigation

Pilot Duty Execution & Emergency Dispatch
  • 1. Start Active Shift: View assigned vehicle (e.g. Bus 245) and click "Start Trip" to engage GPS broadcasting.
  • 2. HUD Waypoint Guidance: Follow glanceable turn-by-turn prompts, stop distance countdowns, and upcoming passenger arrival numbers.
  • 3. Passenger Counter: Update passenger occupancy slider on /driver/occupancy to update system-wide load indicators.
  • 4. Emergency SOS: In case of breakdown or incident, click "Emergency SOS" to trigger deep links for instant WhatsApp (+91 7710893839), Gmail (vsujal956@gmail.com), and SMS broadcast.
👩‍💼

3. Transport Admin Console

Fleet Roster, Driver Dispatch & Alerts
  • 1. Fleet Management: Navigate to /admin/fleet to monitor vehicle operational status, speed, telemetry, and assigned pilots.
  • 2. Dispatch Assignment: Reallocate pilots and routes with instant modal confirmation (e.g. assign Pilot PLT-042 to Bus 245).
  • 3. Schedule Dispatcher: Create and publish daily and weekly timetable trips on /admin/schedules.
  • 4. Advisory Broadcasts: Publish public service announcements on /admin/alerts that notify commuters in real-time.
👨‍💻

4. System Operations Center (SOC)

Infrastructure Health, Telemetry & Security
  • 1. Server Telemetry: Monitor live CPU usage, memory allocation, active socket sessions, and API response latencies on /soc/telemetry.
  • 2. Database Snapshot Backups: Trigger automated or manual point-in-time MongoDB snapshots on /soc/backups.
  • 3. Security & Audit Logs: Inspect every authenticated API call, role transition, and emergency SOS event in the immutable audit log.
🤖

5. AI Intelligence Center

Predictive Analytics & Human-in-the-Loop Approvals
  • 1. Anomaly Watchdog: Filter detected anomalies across Fleet, GPS, Occupancy, API, and Routes on /ai/anomalies.
  • 2. Demand Forecast Matrix: View hourly passenger density heatmaps on /ai/demand to predict peak-hour bottlenecks.
  • 3. Human-in-the-Loop Approvals: Review AI optimization recommendations on /ai/recommendations and click Approve or Reject before execution.
🎛️

6. Sandbox Controls & Shortcuts

Instant Role Switcher & Live Simulation Triggers
  • 1. Role Switcher: Switch personas immediately from the header dropdown (Priya Nambiar ➔ Vikram Jadhav ➔ Aarav Sharma ➔ Devraj Sen).
  • 2. Sandbox Simulator: Click "Sandbox Controls" in the header to simulate Crowd Surge (+40% load), GPS Signal Dropout, or Bus Delay events.
  • 3. Quick Command Search: Press Ctrl + K to search routes, vehicles, stops, or modules anywhere in the app.
